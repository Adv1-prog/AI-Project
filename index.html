Problem Formulation

The 8-Puzzle is a 3×3 grid with 8 numbered tiles (1–8) and one empty blank slot. Adjacent tiles slide into the blank. The goal is reaching a target arrangement in the fewest moves.

State space elements
  • State — 9-element permutation of {0,1,…,8}
  • Actions — Slide blank UP / DOWN / LEFT / RIGHT
  • Path cost — Unit cost c = 1 per tile move

Solvability Check

Inversion Parity

Not all configurations are reachable. A state is solvable if and only if the parity of inversions matches between initial and goal states. An inversion is any pair (a, b) where a > b and a appears before b (ignoring blank).

inversions(initial) % 2 === inversions(goal) % 2

The solver checks this condition automatically before starting BFS.

Section 8 · Documentation

Algorithm 1: Breadth-First Search (BFS)

Time O(bd) Space O(bd)
Description

Breadth-First Search traverses the state-space graph level by level. Starting at the root (initial state), BFS expands all nodes at depth k before expanding any node at depth k + 1, guaranteeing the shortest path under uniform step cost.

Working Principle
  1. Push initial state onto the FIFO queue; add to frontier set.
  2. If queue empty → return failure.
  3. Dequeue node n; add to explored (closed) set.
  4. If n matches goal → reconstruct path via parent pointers → success.
  5. Generate all valid successors (Up / Down / Left / Right).
  6. Enqueue each successor not in explored or frontier; record parent pointer.
  7. Repeat from step 2.
Advantages & Limitations
Advantages
  • Complete — finds solution if one exists.
  • Optimal — minimum number of moves (unit cost).
  • Never gets trapped in infinite depth loops.
Limitations
  • High memory — stores all nodes O(bd).
  • Uninformed — no heuristic guidance toward goal.
  • Exponential expansion for deep solutions.
