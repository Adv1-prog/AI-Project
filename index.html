🎯 8-Puzzle Problem Formulation

The 8-Puzzle is a classical state-space search problem consisting of a $3 \times 3$ grid with 8 numbered sliding square tiles ($1$ to $8$) and one empty slot (represented by _ or 0).

Tiles adjacent to the blank space can slide into the empty spot. The goal is to reach a designated target arrangement starting from an initial configuration with the minimum number of moves.

Formal State Space Elements:
  • State: Array of 9 numbers representing tile placements.
  • Successor Function: Slide the empty tile UP, DOWN, LEFT, or RIGHT within boundaries.
  • Path Cost: Unit step cost $c = 1$. Total cost equals number of moves.

⚖️ BFS Working Principle & Solvability

Breadth-First Search (BFS) expands the shallowest unexpanded node first using a First-In, First-Out (FIFO) queue. It guarantees finding the shortest possible sequence of moves (optimality) because each step cost is equal to 1.

Inversion Parity Solvability Check:

An 8-puzzle configuration is solvable if and only if the number of inversions in the initial state has the same parity (even/odd) as the goal state. Our solver checks this mathematically before starting.

📖 Breadth First Search (BFS) Analysis

Section 8 Documentation

Algorithm 1: Breadth First Search (BFS)

Time: O(b^d) Space: O(b^d)
1. Description

Breadth-First Search (BFS) is a fundamental uninformed search strategy that traverses the state space graph level by level. Starting at the root (initial state), BFS expands all nodes at depth $k$ before expanding any node at depth $k + 1$.

2. Working Principle

BFS employs a First-In, First-Out (FIFO) queue data structure for its frontier:

  1. Initialize the FIFO queue with the initial state node and add it to the frontier set.
  2. If the queue is empty, terminate with failure (no solution).
  3. Dequeue the first node $n$ from the frontier and add it to the explored (closed) set.
  4. If $n$ matches the goal state, backtrack along parent pointers to return the optimal solution path.
  5. Otherwise, generate all valid successor states by sliding the blank tile (Up, Down, Left, Right).
  6. For each successor not already explored or in the frontier, enqueue it and record its parent pointer.
3. Advantages & Limitations
Advantages:
  • Complete: Guaranteed to find a solution if one exists on a finite graph.
  • Optimal: Guaranteed to find the minimal number of moves when all actions have equal step cost ($c = 1$).
  • Never gets trapped in infinite depth loops.
Limitations:
  • High Memory Footprint: Must retain every generated node in memory ($O(b^d)$ space).
  • Uninformed: Explores uniformly in all directions without heuristic guidance toward the goal.
4. Complexity, Completeness & Optimality Matrix
Property Value Explanation
Time Complexity O(b^d) With effective branching factor $b \approx 3$ and goal depth $d$, up to $b^d$ nodes are visited.
Space Complexity O(b^d) Stores all frontier and explored nodes in RAM.
Completeness Yes Guaranteed to terminate with solution if finite state space and finite branching factor $b$.
Optimality Yes Finds the shallowest goal node (minimum moves) since step cost $c = 1$.
